# Agent Pigeon — private test

## Install

```bash
npm install -g ./agent-pigeon-0.1.0.tgz
```

## Flight report

```bash
agent-pigeon flight
```

## Another session

```bash
agent-pigeon flight --session <id-prefix>
```

## Compare

```bash
agent-pigeon compare <sessionA> <sessionB>
```

## Share

```bash
agent-pigeon share flight > flight.svg
agent-pigeon share compare > compare.svg
```

## Uninstall

```bash
npm uninstall -g agent-pigeon
```
